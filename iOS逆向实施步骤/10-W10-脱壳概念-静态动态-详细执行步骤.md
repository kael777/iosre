## 本周在练什么

W9 已经证明：自建 SignDemo 的 **`cryptid = 0`**。W10 要搞清三件事：

```text
1. FairPlay / cryptid 1 是什么，和自建包差在哪
2. 为什么对 SignDemo「脱壳」几乎学不到商店脱壳
3. Ghidra 里看到的 HMACSigner，怎样和 Frida 运行时对上
```

**FairPlay**：App Store 下发的 Mach-O 有一段代码在磁盘上是加密的（`cryptid 1`）。系统加载进内存、通过 DRM 后才会解密。静态打开商店主二进制，Ghidra 里 `__TEXT` 往往是乱码。  
**脱壳**：在进程已经解密之后，把内存中的明文 Mach-O 转储出来。这不是「破解 App」，是拿一份自己有权分析的、可静态阅读的副本。

自建 Xcode 包 **从来没有** 这段加密，所以：

- `otool` 能直接看到 `HMACSigner`
- Ghidra 能直接反编译
- 对它跑 dump，得到的文件和 `artifacts/SignDemo` 几乎同类（本来就是明文）

这就是验收要说的：**自建未加密 App 不能代表商店 App 的脱壳过程。**

## 执行 1：FairPlay 概念 + 复核 SignDemo

### 1.1 术语

| 术语 | 含义 |
|---|---|
| **FairPlay** | 苹果对商店 App 的 DRM。部分代码段在磁盘加密，运行时由系统解密。 |
| **cryptid** | `LC_ENCRYPTION_INFO(_64)` 里的标志。`0` 未加密，`1` 加密。 |
| **cryptoff / cryptsize** | 加密区间的文件偏移和长度。有这两个数不等于正在加密，还要看 cryptid。 |
| **脱壳 dump** | 从已解密的进程内存写出 Mach-O。对象必须是自己有权分析的包。 |
| **rootless** | Dopamine 这类越狱：系统分区只读，dump 工具路径、权限和旧越狱不同。 |

### 1.2 再看一次自己的包

```bash
otool -l /Users/weideshun/Downloads/ll/artifacts/SignDemo | grep -A 6 LC_ENCRYPTION_INFO
```

应仍是 `cryptid 0`。把这一行抄进本周笔记，作为「未加密基线」。

## 执行 4：静态位置 ↔ 动态调用

这是本周主实验，不依赖 dump。

### 4.1 填这张表（HMACSigner）

从 W9 报告和 W7 笔记抄，缺的就再开一次 Frida 只读脚本核对。

| 项 | 静态（nm / Ghidra） | 动态（Frida） | 源码 |
|---|---|---|---|
| 类 | `HMACSigner` | `ObjC.classes.HMACSigner` | `HMACSigner.m` |
| newNonce | `+[HMACSigner newNonce]` @ `0x10000850c`（文件里） | `["+ newNonce"]`，点 Login 进入 | `+ newNonce` |
| canonical | 符号 + 字符串 `user_id=%@&timestamp=%lld...` | 返回值 `user_id=&timestamp=&nonce=&action=` | 同左 |
| sign | `+[HMACSigner signWithUserID:...]` | 返回 64 位 hex | `CCHmac` |
| secret | strings：`local-demo-secret-v1` | 观察脚本可打到参数/常量 | `APIConfig.m` |
| timestamp 类型 | Ghidra 可能显示 `undefined8` | Frida 打印整数 | `long long` |

PIE：Ghidra / nm 的 `0x10000xxxx` 是 **未加载** 地址。Frida 里 `Module` 基址 + 偏移才是运行时地址。对不上绝对值是正常的，对 **符号名** 即可。

### 4.2 走一遍闭环

```text
Ghidra 打开 +[HMACSigner canonicalString...]
→ 记下函数名（不要死记文件偏移）
→ frida -U -n SignDemo -l hook_network_request.js
→ 点 Login
→ 确认进入同一方法、canonical 格式一致
→ 若 Ghidra 把 timestamp 画成指针：以 Frida 为准，回去在笔记里改推断
```

这就是计划里的：

```text
字符串初筛 → 符号定位 → xref → Frida 验证 → 修正 Ghidra 推断
```

### 4.3 验收标准

- [x] 表里至少 4 行填满
- [x] 能说明文件偏移 ≠ 运行时地址（PIE）
- [x] 能说明 Ghidra 伪代码不是原始源码（沿用 timestamp 例子即可）
