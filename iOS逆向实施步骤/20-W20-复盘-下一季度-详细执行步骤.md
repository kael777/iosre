## 执行 2：独立命令（证明还能跑）

XR 解锁、USB 连接。不必重做 W4–W19 全套。

```bash
# 设备与 Frida
frida-ps -U
frida-ps -Uai | grep -E 'SignDemo|InsecureApp|uncrackable'

# 工程
xcodebuild -version
cd /Users/weideshun/Desktop/SignDemo/backend
./.venv/bin/python3 -m pytest -q

# 后端若没在跑：再开一个终端
./.venv/bin/python3 app.py
# 然后：
./.venv/bin/python3 ../scripts/reproduce/replay_local_request.py --mode secure
```

`frida-ps -U` 能列出进程即可。pytest 应仍绿。`--mode secure` 应 ALL PASS（不要带 `SIGNDEMO_DEFECT_*`）。

若 5443 被旧进程占用，先停掉再启。真机 Health 用 `https://192.168.1.8:5443`，不要 `127.0.0.1`。

反调试开关保持 **关**。

### 验收标准

- [x] `frida-ps -U` 成功
- [x] pytest 通过
- [x] 至少一次本机 `replay --mode secure` 或真机 Health 成功

## 执行 3：三张表（写进执行记录，执行 4 再收进复盘）

### 3.1 哪些工具仍需查资料

已会独立用、和「还要翻手册」分开。例如：Frida 17 没有 `Module.findExportByName`、Ghidra AARCH64、Theos rootless、`libarclite`。

### 3.2 哪些失败可以快速定位

本季度已经踩过、下次能直接想到的，例如：

| 现象 | 先查 |
|---|---|
| 真机连不上后端 | URL 是不是 `127.0.0.1` |
| mitmproxy 证书错误 | Pinning 开没开、ATS、上游 CA |
| `python: command not found` | 用 `.venv/bin/python3` |
| 免费账号装不上第四个 App | 3 App 上限，先删一个 |
| Frida hook 字符串崩溃 | 17 的 NSString / 不要乱 `replace` |
| IDOR 脚本 E 仍 200 | `app.py` 是不是旧进程、没加载 ACL |
| 越狱检测全 NO | 是不是只查了 Cydia（Dopamine 漏报） |

按自己的话改，不要整段复制。

### 3.3 哪些结论只在自建环境成立

必须写进复盘，避免作品集看起来像「生产审计」：

- HMAC secret、Pinning 哈希、虚构用户只属于 SignDemo
- `cryptid=0` 是 Debug / 免费证书，不是商店 FairPlay 已脱壳
- IDOR 修复前后对照只打了 `127.0.0.1`
- Dopamine rootless 的路径 ≠ 网上 Cydia 教程
- 客户端检测被 hook ≠ 后端被打穿

### 验收标准

- [x] 三张表都有至少 3 行自己的话
