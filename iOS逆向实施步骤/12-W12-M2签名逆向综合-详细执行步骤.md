## M2 是什么

M1（W6）是：观察流量 → 识别参数 → 复现请求。  
M2 是在 **secret 已经混淆** 的前提下，再走一遍：

```text
按钮
→ ObjC 调用链
→ SecretStore 还原 secret
→ HMACSigner 算出 sign
→ 发出 /api/login、/api/order
→ Python 离线算出相同 sign
→ 改 timestamp / nonce 会被后端拒绝
```

验收里有一句：**不看旧脚本也能重新定位签名入口。**  
意思是：本周写报告时，按下面顺序自己点一遍 Ghidra / Frida，不要只复制 W11 笔记交差。旧脚本可以当对照，不能当唯一依据。

## 执行 1：调用链（先自己走）

打开 Xcode 源码（可以看，尽量先不看 `sign_v2.py`），从 `loginButtonTapped:` 往下跟：

```text
ViewController loginButtonTapped:
  → APIClient loginWithUserID:password:completion:
      → signedBodyForAction:userID:
          → HMACSigner newNonce
          → SecretStore currentSecret
              → 开关关：obfuscatedSecret（XOR 0x5A）
              → 开关开：SignDemoSigningSecret 字面量
          → HMACSigner signWithUserID:timestamp:nonce:action:secret:
              → canonicalStringWithUserID:...
              → hexHMACSHA256WithMessage:secret:   （CCHmac）
      → POST /api/login  JSON
```

order 相同，`action=order`，再加 `order_id`、`amount`（这两项 **不进** canonical）。

把链抄进报告第 5 节。能指着屏幕说「secret 从哪来、sign 在哪算、哪一步发出去」就算过。

