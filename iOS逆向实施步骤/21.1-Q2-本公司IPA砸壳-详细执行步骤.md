# Q2 本公司 IPA 砸壳操作手册

> 只对本公司 IM、自己的 XR（Dopamine）。  
> 不要砸微信/银行/别人的商店包，不要把砸完的 IPA 发给别人当「免商店安装包」。  
> 外层：[`iOS逆向_2026Q2完整实施计划.md`](../iOS逆向_2026Q2完整实施计划.md)  
> 注册主线：[`21-Q2-公司IM注册链路-详细执行步骤.md`](21-Q2-公司IM注册链路-详细执行步骤.md)

砸壳是为了 **Ghidra / strings 能看 `__TEXT`**。抓注册接口、改指纹字段（执行 3～5）**不依赖** 砸壳，运行时 Frida 也能做。

## 0. 先判断要不要砸

```bash
# 把公司 ipa 放到 gitignore 目录，不要 commit
mkdir -p ~/Downloads/ll/artifacts/myim
# 自行复制：cp /path/to/公司.ipa ~/Downloads/ll/artifacts/myim/myim.ipa

IPA=~/Downloads/ll/artifacts/myim/myim.ipa
DEST=~/Downloads/ll/artifacts/myim/unpacked
rm -rf "$DEST" && mkdir -p "$DEST" && unzip -q "$IPA" -d "$DEST"
APP=$(find "$DEST/Payload" -name '*.app' -maxdepth 1 | head -1)
echo "APP=$APP"
/usr/libexec/PlistBuddy -c 'Print :CFBundleIdentifier' "$APP/Info.plist"
/usr/libexec/PlistBuddy -c 'Print :CFBundleExecutable' "$APP/Info.plist"
BIN="$APP/$(/usr/libexec/PlistBuddy -c 'Print :CFBundleExecutable' "$APP/Info.plist")"
otool -l "$BIN" | grep -A2 cryptid
```

| cryptid | 做什么 |
|---|---|
| **0** | **不用砸。** 开发包/企业测包常态。直接去注册主线执行 2。 |
| **1** | FairPlay。必须先在本机 XR **能打开** 这个 App，再 dump 内存。 |
| 没有 `LC_ENCRYPTION_INFO` | 当 0 处理。 |

把 Bundle ID 抄下来，下文写成 `com.company.myim`（换成真实值）。

## 1. 砸壳在干什么

商店包磁盘上代码加密。这台 XR 用有效许可装上并启动后，内核在 **内存** 里解密。  
砸壳 = 从正在跑的进程把明文 Mach-O 写出来，并把 header 里 `cryptid` 改成 0。

因此：

- **没装上、打不开** → 砸不了（密钥不在这台机上）。
- 砸的是 **这台设备正在运行的那份**，不是对 zip 里的加密文件「解密算法」。
- iOS 18.5 + Dopamine rootless + Frida 17：**没有官方保证**，失败就改用运行时分析，不要硬套老教程。

## 2. 环境

Mac 与 XR USB 直连，XR 解锁，信任电脑。

```bash
frida --version          # Q1 为 17.x
frida-ps -U | head
iproxy -h | head -1      # 来自 libimobiledevice
```

Dopamine 的 SSH 常见是 **端口 44**（rootless），密码默认有人仍是 `alpine`（若你改过就用你的）。

```bash
# 另开一个终端，一直挂着
iproxy 2222 44
```

再开终端测：

```bash
ssh -p 2222 root@127.0.0.1
# 能进去即可。rootless 上可执行文件多在 /var/jb
```

进不去时：Filza 看 OpenSSH 是否安装、端口是 22 还是 44，把 `iproxy 2222 44` 改成实际端口。

- 用 **能运行这份包的账号** 安装（TestFlight / 企业签 / 同一台已登录的商店版）。

```bash
frida-ps -Uai | grep -i myim
```

看到 Bundle ID 再往下。看不到 = 没在跑或 Bundle 名不对。

## 4. 方法 A：bagbak（优先试）

在 Mac：

```bash
npm install -g bagbak
bagbak --help
```

App **留在前台**，然后：

```bash
cd ~/Downloads/ll/artifacts/myim
bagbak com.company.myim
```

成功时当前目录会多出一个 **已砸** 的 ipa 或 app。把主二进制再查一次：

```bash
# 按实际解压路径改
otool -l ./Payload/*.app/主执行文件名 | grep -A2 cryptid
```

应为 **cryptid 0**。  
若报 Frida 连不上、spawn 失败、iOS 版本不支持：改方法 B，不要循环重装。

## 5. 方法 B：Frida dump（Frida 17）

不要用停更的 AloneMonkey 原版（停在 2023，且旧 API）。优先 README 写明 **Frida 17** 的 fork（Q1 记过 `incogbyte/frida-ios-dump-ng` 一类）。

```bash
cd ~/Downloads/ll/artifacts/myim
git clone --depth 1 https://github.com/incogbyte/frida-ios-dump-ng.git
cd frida-ios-dump-ng
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # 以该仓库 README 为准
```

`iproxy 2222 44` 仍要挂着。按该仓库 README 改 `dump.py` 里的 SSH 端口/用户（常见 `root@127.0.0.1:2222`）。

App 在前台：

```bash
python3 dump.py com.company.myim
```

产物同样放到 `artifacts/myim/`，**不要 git add**。

Frida 17 若脚本里还有 `Module.findExportByName`，会直接挂（Q1 已踩过）。换适配 17 的 dump，或放弃砸壳、改执行 3 只做流量。

## 6. 验收（砸完必须做）

```bash
BIN=砸完后的主二进制路径
file "$BIN"
otool -l "$BIN" | grep -A2 cryptid
strings "$BIN" | grep -E 'https://|login|device' | head
```

| 检查 | 预期 |
|---|---|
| `file` | `Mach-O 64-bit executable arm64`（或 arm64e） |
| cryptid | **0** |
| strings | 能看到 URL / 类名一类明文（加固包仍可能很少） |

cryptid 仍是 1 = dump 失败，磁盘还是加密段。不要拿去喂 Ghidra。

## 7. 失败时怎么办（Q2 主线不挡）

| 现象 | 处理 |
|---|---|
| cryptid 本来就是 0 | 不砸，去做注册四步 |
| 设备上打不开 App | 换能装的签；砸不了 |
| SSH 连不上 | 先保证 `frida-ps -U`；bagbak 有时只靠 USB Frida |
| dump 闪退 / Frida `findExportByName` | iOS 18 + Frida 17 不兼容该脚本 |
| 砸完还是乱码 | 加固/OLLVM，不代表没砸开；改用 Frida 看注册请求 |

**注册机问题不靠砸壳解决。** 手册 21 的执行 3～5（抓包、改指纹）始终可以先做。

## 不要做的事
