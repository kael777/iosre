# Q2 改 plist 后用 zsign 重签并装到测试机

> 实测跑通：解包现成 IPA → 改 `Info.plist` → zsign（个人开发证书）→ USB 装到自己的测试机。  
> 不需要 TrollStore、不需要 Fastlane、不需要 Distribution 证书。  
> 只签 **自己的 / 公司授权的** 测包，不要拿商店第三方包当破解包分发。

---

## 结论（先看这个）

改完 plist 必须用 **同一套** 东西重签，缺一不可：

1. `.p12`：钥匙串里 **Apple Development: 你的 Apple ID**（带私钥）
2. `.mobileprovision`：**同一个 Team**、**同一个 Bundle ID**、**这台测试机 UDID 已登记**
3. zsign 的 `-b` 必须和 profile 里的 App ID **完全一致**
4. 用 Xcode / Sideloadly **USB 安装**，不要用 Filza 系统安装

主屏幕有图标 ≠ 能打开。点开「无法验证其完整性」= 上面 2 或 3 没对上，或没在系统设置里信任开发者。

---

## 1. 解包并改 plist

```bash
WORKDIR=~/Downloads/ll/artifacts/unpacked
# 已解压的 IPA 应是：
#   unpacked/Payload/*.app/Info.plist

APP=$(find "$WORKDIR/Payload" -name '*.app' -maxdepth 1 | head -1)
plutil -convert xml1 "$APP/Info.plist"
# 按需要改键（显示名、ATS、URL Scheme 等）
plutil -lint "$APP/Info.plist"
```

不要把 `unpacked` 直接 zip 当成品去装。成品必须是 zsign 输出的 ipa。

---

## 2. 导出 p12

钥匙串访问 → 登录 → **我的证书** → `Apple Development: 你的AppleID`  
（左边要有钥匙）→ 导出 `.p12`，设密码。

本机有多张证时，看 Common Name，不要导成别的同事 / 别的公司 Team 的证。

```bash
security find-identity -v -p codesigning
```

---

## 3. 用 Xcode 生成「对得上」的描述文件（关键）

描述文件必须同时满足：这个 Bundle ID、这张证所在 Team、这台手机。

1. Xcode → Settings → Accounts → 登录 **同一个** Apple ID  
2. USB 连测试机并信任  
3. 新建空 iOS App，Bundle ID 定死一个，例如 `com.example.myimtest`  
4. Signing Team 选这个 Apple ID，勾 Automatic Signing  
5. 选真机 Command+R 装一次空 App（成功即可删掉空 App）

Xcode 会把该机 UDID 写进 profile。文件在：

```text
~/Library/Developer/Xcode/UserData/Provisioning Profiles/
```

核对（把文件名换成最新的 `.mobileprovision`）：

```bash
PROV=~/Library/Developer/Xcode/UserData/Provisioning\ Profiles/xxxxxxxx.mobileprovision
security cms -D -i "$PROV" > /tmp/prov.plist
/usr/libexec/PlistBuddy -c 'Print :Name' /tmp/prov.plist
/usr/libexec/PlistBuddy -c 'Print :TeamName' /tmp/prov.plist
/usr/libexec/PlistBuddy -c 'Print :Entitlements:application-identifier' /tmp/prov.plist
/usr/libexec/PlistBuddy -c 'Print :ProvisionedDevices' /tmp/prov.plist
idevice_id -l
```

`application-identifier` 应是 `TEAMID.` + 你在 Xcode 填的 Bundle ID。  
`ProvisionedDevices` 里必须有 `idevice_id -l` 打出来的那台。

---

## 4. zsign

[zsign](https://github.com/zhlynn/zsign) 最后一个参数是 **解压目录**（里面要有 `Payload/`），不是原始 ipa。

`-b` = profile 里那个 Bundle ID（整段点后面的名字，不要少后缀）。

```bash
PROV=~/Library/Developer/Xcode/UserData/Provisioning\ Profiles/你的.mobileprovision

./zsign \
  -k ~/Downloads/你的.p12 \
  -p 'p12密码' \
  -m "$PROV" \
  -b com.example.myimtest \
  -o ~/Downloads/ll/artifacts/resigned.ipa \
  ~/Downloads/ll/artifacts/unpacked
```

成功日志里应对上：

- `SubjectCN: Apple Development: 你的AppleID`
- `BundleId:` 与 `-b` 相同
- `TeamId:` 与 profile 的 Team 相同
- `Signed OK` / `Archive OK`

---

## 5. 安装到测试机

1. 长按删掉主屏幕上 **旧图标**（换过 Bundle ID 会留多个坏图标）。  
2. USB 连接。用 **Xcode → Window → Devices and Simulators** 把 `resigned.ipa` 拖进设备，或用 Sideloadly。  
3. 设置 → 通用 → **VPN 与设备管理** → 信任该开发者。  
4. 设置 → 隐私与安全性 → **开发者模式** 打开（按提示重启）。  
5. 若提示要联网验证：换 **蜂窝数据** 再点图标（国内部分 Wi‑Fi 到不了苹果验证服务器）。

免费开发证书大约 **7 天**，过期再签一次。

---

## 踩过的坑（不要再走）

| 做法 | 结果 |
|---|---|
| 只 zip、不 zsign | 完整性失败 |
| Filza / 系统「安装」ipa | 验苹果签，失败 |
| p12 是 A 账号，profile 是 B 公司通配 | 能打出 ipa，点不开 |
| `-b` 写成 `com.xxx.myimtest`，profile 却是 `com.xxx.myimtest.imDemo` | 有图标，提示无法验证完整性 |
| 测试机 UDID 不在 `ProvisionedDevices` | 同上 |
| 不删旧图标，点的是上一版 | 同上 |
| Fastlane + `Apple Distribution` | 个人账号没有这张证，用不上 |
